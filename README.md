# Proyecto Integrador Diplomatura Power BI (MUNDOSE)

## 📊 Desarrollo Completo Punta a Punta Proyecto Dashboard Ventas Power BI

Mediante este proyecto integrador se realizo un dashboard de ventas desde 0, partiendo de tablas con datos crudos
Realizando un analisis exploratorio de datos seguido de un proceso ETL con power query.
Posteriormente un modelado de datos, formulando luego mediante DAX los KPIs necesarios para analizar el desempeño.
Finalmente se realiza el armado del dashboard con la visualizaciones necesarias para mostrar info estrategica
y presentando los resultados con storytelling
